Aerial Human Detection - Team Git Manager V2

Main file:
    aerial-git-manager-v2.cmd

Configured repository:
    D:\A_Senior - Data Science\Projects\aerial-human-detection

Main features:
- Update, push, and full synchronization in one script
- Colored interface and dashboard
- Overall 0-100% operation progress bars
- Native Git download and upload percentages
- Git transfer speed shown by Git during push/fetch
- Shared operation lock
- Merge-conflict detection
- Teammate identity profiles
- Editable name and email before every commit
- Custom commit message
- Commit-hash verification after upload
- Recent commit history
- Repository diagnostics
- Logs stored outside the repository

Important:
- The overall blue bar represents operation-stage progress, not transferred bytes.
- Exact transfer progress is printed by Git itself during fetch/push.
- Small network operations may finish before Git prints a percentage.
- Only one teammate should use the shared folder at a time.
