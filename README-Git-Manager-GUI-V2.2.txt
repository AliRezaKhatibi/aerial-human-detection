Aerial Human Detection - Git Manager GUI V2.2 Portable

FIXED IN V2.2
- Git informational messages written to stderr are no longer treated as failures.
- "Already on 'main'" is now recognized as a successful Git operation.
- Git success and failure are determined from the actual native Git exit code.
- Branch switching uses quiet mode to reduce harmless terminal messages.
- The repository path remains portable and is saved separately on each computer.

RUN
Double-click:
    Launch-Git-Manager-GUI-V2.2.vbs

Alternative:
    launch-git-manager-gui-v2.2.cmd

IMPORTANT
Extract all package files before running.
